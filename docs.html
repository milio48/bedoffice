Developer Integration Guide

Embed the client-side ONLYOFFICE WASM suite into any web app via bedoffice iframe bridge with zero backend servers and instant byte stream extraction.

Zero Document Server Required Document conversion, editing, and rendering run entirely inside the client browser using ONLYOFFICE WebAssembly (x2t.wasm). Files never leave the user's browser.

Quick Start (Vanilla JavaScript)

Embed the editor via an <iframe> using the hosted bridge (or your self-hosted path) and inject your document configuration with postMessage:

index.html 
<!-- Use the hosted CDN bridge or your own self-hosted onlyoffice.html -->
<iframe id="office-frame" 
        src="https://milio48.github.io/bedoffice/onlyoffice.html" 
        style="width: 100%; height: 100vh; border: none;"></iframe>

<script>
const iframe = document.getElementById('office-frame');

window.addEventListener('message', (event) => {
    const data = event.data;
    if (!data) return;

    // 1. When iframe bridge is ready, inject docConfig
    if (data.type === 'onlyoffice-ready') {
        iframe.contentWindow.postMessage({
            type: 'onlyoffice-config',
            docConfig: {
                document: {
                    url: 'https://example.com/sample.docx',
                    title: 'Sample Document.docx',
                    fileType: 'docx'
                },
                editorConfig: { 
                    lang: 'en-US', 
                    mode: 'edit' 
                }
            }
        }, '*');
    }

    // 2. Receive edited file byte stream (ArrayBuffer)
    if (data.type === 'onlyoffice-saved' && data.ok) {
        const fileBlob = new Blob([data.buffer]);
        console.log(`Received saved file (${fileBlob.size} bytes):`, data.fileName);
        // Upload fileBlob to your backend or save locally!
    }
});

// To programmatically trigger a save:
function saveDocument() {
    iframe.contentWindow.postMessage({ 
        type: 'onlyoffice-save', 
        requestId: 'req_' + Date.now() 
    }, '*');
}
</script>

Architecture & Window Hierarchy

The system operates in a three-tier communication hierarchy:

  • Host Application (Your App): Issues save/export commands, controls permissions, and receives binary ArrayBuffer streams.
  • onlyoffice.html (Integration Bridge): Manages the DocsAPI instance, handles window messaging, and suppresses browser auto-downloads.
  • ONLYOFFICE WASM Core: Executes x2t.wasm in-memory to convert, format, and generate binary Office files.

postMessage IPC Protocol Reference

Events Emitted by onlyoffice.html

Event Name Payload Description
onlyoffice-ready none Sent when the bridge iframe is mounted and ready for onlyoffice-config.
onlyoffice-document-ready none Fired when ONLYOFFICE finishes rendering the document on canvas.
onlyoffice-saved ok: bool, buffer: ArrayBuffer, fileName: str, requestId?: str Delivers the raw binary stream after save or export.
onlyoffice-open-error error: string Triggered if document loading fails.
onlyoffice-state-change modified: boolean Emitted when document changes unsaved status.

Commands Dispatched to onlyoffice.html

Command Name Parameters Description
onlyoffice-config docConfig: object, openBuffer?: ArrayBuffer Initializes and opens the document editor.
onlyoffice-save requestId?: string, format?: string Instructs WASM engine to convert and extract raw file bytes.
onlyoffice-set-name name: string Updates the active document title.

File Stream Extraction

Because there is no backend Document Server to handle save callbacks, bedoffice intercepts x2t.downloadFile inside the WebAssembly layer. When saving or exporting, the raw binary byte stream is returned as an ArrayBuffer inside the onlyoffice-saved event, allowing host applications to save files directly into custom databases, S3 buckets, or local storage without opening native browser download popups.

Complete API Recipes (Vanilla JS)

Practical recipes for every event and command in the bedoffice bridge:

1. Promise-based Save & Format Export

Request an asynchronous save with promise matching, or export to a different format (e.g. DOCX ➔ PDF):

save-and-export.js 
/**
 * Saves or exports the active document and returns a Promise resolving to a Blob.
 * @param {HTMLIFrameElement} iframeEl
 * @param {'docx'|'xlsx'|'pptx'|'pdf'} [exportFormat]
 * @returns {Promise<Blob>}
 */
function requestDocumentSave(iframeEl, exportFormat) {
    return new Promise((resolve, reject) => {
        const requestId = 'req_' + Math.random().toString(36).slice(2, 9);
        const timeout = setTimeout(() => {
            window.removeEventListener('message', onSaved);
            reject(new Error('Save operation timed out'));
        }, 30000);

        function onSaved(event) {
            const data = event.data;
            if (data && data.type === 'onlyoffice-saved' && data.requestId === requestId) {
                clearTimeout(timeout);
                window.removeEventListener('message', onSaved);
                if (data.ok && data.buffer) {
                    resolve(new Blob([data.buffer]));
                } else {
                    reject(new Error(data.error || 'Failed to save document'));
                }
            }
        }

        window.addEventListener('message', onSaved);
        iframeEl.contentWindow.postMessage({
            type: 'onlyoffice-save',
            requestId: requestId,
            format: exportFormat // Omit for native format, or specify 'pdf', etc.
        }, '*');
    });
}

// Example usage:
// const pdfBlob = await requestDocumentSave(iframe, 'pdf');

2. Open from In-Memory Binary Buffer (`ArrayBuffer`)

For opening files directly from memory, IndexedDB, or file upload input without generating a web URL:

open-binary.js 
async function openLocalBinaryFile(iframeEl, file) {
    const arrayBuffer = await file.arrayBuffer();
    const ext = file.name.split('.').pop().toLowerCase();

    const docConfig = {
        document: {
            title: file.name,
            fileType: ext,
            key: 'doc_' + Date.now(),
            permissions: { edit: true, download: true, print: true }
        },
        localOpenFromBinary: true, // Instructs bridge to load from memory buffer
        editorConfig: { lang: 'en-US', mode: 'edit' }
    };

    // Pass openBuffer in the message transfer list for zero-copy performance
    iframeEl.contentWindow.postMessage({
        type: 'onlyoffice-config',
        docConfig: docConfig,
        openBuffer: arrayBuffer
    }, '*', [arrayBuffer]);
}

3. Tracking Unsaved Modifications (Dirty State)

Listen for unsaved changes to prompt users before navigating away:

state-change.js 
let isDocumentDirty = false;

window.addEventListener('message', (event) => {
    const data = event.data;
    if (!data) return;

    if (data.type === 'onlyoffice-state-change') {
        isDocumentDirty = data.modified;
        console.log('Unsaved changes:', isDocumentDirty);
    }
});

window.addEventListener('beforeunload', (e) => {
    if (isDocumentDirty) e.preventDefault();
});

4. Dynamic Renaming, Save-As & Close Events

event-handlers.js 
// 1. Programmatically rename document header
function renameActiveDocument(iframeEl, newTitle) {
    iframeEl.contentWindow.postMessage({
        type: 'onlyoffice-set-name',
        name: newTitle
    }, '*');
}

// 2. Listen for editor events (Rename, Save-As Copy, Close request)
window.addEventListener('message', (event) => {
    const d = event.data;
    if (!d) return;

    switch (d.type) {
        case 'onlyoffice-rename':
            console.log('User renamed document to:', d.title);
            break;

        case 'onlyoffice-saveas':
            if (d.ok && d.buffer) {
                console.log('User created copy:', d.fileType, new Blob([d.buffer]));
            }
            break;

        case 'onlyoffice-request-close':
            console.log('User clicked editor close button');
            // Hide iframe or navigate back
            break;
    }
});
